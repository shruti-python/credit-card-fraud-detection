# Credit Card Fraud Detection

Credit card fraud detection is a Machine Learning application that identifies fraudulent transactions by analyzing transaction patterns and customer behavior. With the rapid growth of digital payments and e-commerce, detecting fraud accurately has become essential to protect financial institutions and customers from financial losses.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Logistic Regression
- XGBoost

## Dataset
Credit Card Fraud Detection Dataset{Kaggle}
